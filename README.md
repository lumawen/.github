<p align="center"><b>Guitars and the tools around them, built in the open.</b></p>

Lumawen is building:

- **Hexaphonic pickups**: one signal per string
- **Custom guitars** designed around them
- **An AI-assisted app** for learning guitar and music theory
- **Open-source hardware**: schematics, diagrams and build instructions, right here

### Repositories

| Repo | What's in it |
| --- | --- |
| [lumawen-pickups](https://github.com/lumawen/lumawen-pickups) | Pickup designs, schematics and build guides |
